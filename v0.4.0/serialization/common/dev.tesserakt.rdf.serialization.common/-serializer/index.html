class DeserializationProcess : Iterator<Quad> , AutoCloseable

Parses the data obtained from the DataStream as long as the resulting Quads are being consumed using Iterator.next. The opened DataStream is DataStream.closed when no more Quads are available or a DeserializationException is thrown.

class SuspendingDeserializationProcess : SuspendingIterator<Quad> , AutoCloseable

Parses the data obtained from the SuspendingDataStream as long as the resulting Quads are being consumed using Iterator.next. The opened SuspendingDataStream is SuspendingDataStream.closed when no more Quads are available or a DeserializationException is thrown.
