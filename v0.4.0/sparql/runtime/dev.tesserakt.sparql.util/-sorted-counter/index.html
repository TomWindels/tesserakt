SortedCounter

class SortedCounter<T>(val comparator: Comparator<in T>) : Iterable<Map.Entry<T, Int>>

A special Counter implementation that also ensures counted elements are ordered using the comparator. Order is not guaranteed between elements for which the provided comparator yields 0, and the order between such elements can change at any time. Backed by a red-black tree for element ordering and linked lists to track elements with no strict order.
