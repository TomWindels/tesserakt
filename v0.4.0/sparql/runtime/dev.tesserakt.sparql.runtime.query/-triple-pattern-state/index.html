class FilteredArrayBackedTriplePatternState<P : TriplePatternState.Predicate>(context: QueryContext, inner: TriplePatternState.ArrayBackedPatternState<P>, expr: FilterExpression) : TriplePatternState.ArrayBackedPatternState<P>

A special, optimized variant to filter specific types of triple patterns: knowing that the array backed variants directly store the result of what was TriplePatternState.peeked upon TriplePatternState.processing a data change, we only have to alter that peeked result stream by applying the expr filter once; at join time, the altered backing structure is used, so no additional filtering is required.
